# GlassDesign ML

**Обратное проектирование составов оксидных стёкол с помощью машинного обучения.**

**Состояние проекта:** подготовка самостоятельной веб-версии. Программа пока НЕ опубликована как работающий сайт. В репозитории размещаются исходные модули исследовательского алгоритма и конфигурация; полный публичный пакет и обученные модели ещё необходимо подключить и протестировать.

## Что делает система

- Прогнозирует плотность, показатель преломления, Tg и Tsoft оксидных стёкол.
- Подбирает составы с заданными ограничениями с помощью адаптивного генетического алгоритма.
- Сопоставляет результаты прогнозов GlassDesign ML и GlassNet.
- Экспортирует найденные составы для последующего экспериментального исследования.

**Важно:** предсказанные характеристики и оценки VITRIFY не являются экспериментальным подтверждением свойств или стеклообразования.

## Подготовка публикации

1. Добавить публичный адаптер веб-интерфейса `streamlit_app.py` и адаптер расчётов `glass380_engine.py` из подготовленной демонстрационной сборки.
2. Добавить `glass380_science.py`, каталог `runtime/GlassDesignML/glass_families.json` и проверить все зависимости.
3. Подготовить четыре исходных файла `.joblib` из `YAG_Inverse_Design/GlassDesignML/models/` (примерно 1,2 ГиБ суммарно). Они намеренно исключены из обычных Git-коммитов.
4. Проверить реальный запуск с четырьмя моделями и GlassNet, включая использование памяти.
5. Только после проверки развернуть через Streamlit Community Cloud или сервер с достаточной памятью.

Нельзя загружать в репозиторий токены, ключи доступа, личные данные и необработанные исследовательские базы.
