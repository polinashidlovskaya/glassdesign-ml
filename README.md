# GlassDesign ML

**Обратное проектирование составов оксидных стёкол с помощью машинного обучения и адаптивного генетического поиска.**

GlassDesign ML подбирает расчётные составы по заданным диапазонам плотности, показателя преломления, температуры стеклования (Tg) и температуры размягчения (Tsoft). Программа использует четыре предварительно обученные модели GlassDesign ML и независимые прогнозы GlassNet.

> **Статус:** доступна самостоятельная демонстрация через Google Colab. Это **не постоянно работающий веб-сайт**: при каждом запуске создаётся временная ссылка через Cloudflare Tunnel. Для работы по этой ссылке сеанс Colab должен оставаться активным. Некоторые сети или провайдеры могут ограничивать доступ к доменам `trycloudflare.com`.

## Запуск без установки Python

1. [Откройте блокнот GlassDesignML_Independent_Demo в Google Colab](https://colab.research.google.com/github/polinashidlovskaya/glassdesign-ml/blob/main/GlassDesignML_Independent_Demo.ipynb).
2. Авторизуйтесь в Google при необходимости и выберите **Среда выполнения → Выполнить все**. Подтвердите запуск кода из доверенного репозитория.
3. Блокнот скачает программу из GitHub, зависимости и четыре предварительно обученные модели из Google Drive. При повторном запуске в существующей среде Colab код обновляется из ветки `main`, если в локальных отслеживаемых файлах нет несохранённых изменений.
4. После запуска найдите в последней ячейке сообщение **«GLASSDESIGN ML ОТКРЫТ»** и откройте выданную временную ссылку на `trycloudflare.com`.
5. Задайте химическую систему и диапазоны желаемых свойств, запустите подбор и при необходимости скачайте результаты в CSV.

Первый запуск может быть продолжительным из-за загрузки моделей и подготовки GlassNet. Не закрывайте активную среду выполнения Colab во время работы с приложением.

## Что умеет программа

- Задавать допустимые диапазоны свойств и ограничения концентраций оксидов.
- Автоматически выбирать перспективные семейства стёкол либо работать с выбранными семействами/оксидами.
- Находить новые составы адаптивным генетическим поиском.
- Проверять соответствие диапазонам по двум прогнозным модулям без усреднения результатов.
- Показывать подходящие и ближайшие неподходящие варианты, карточки, подробные таблицы и CSV.
- При наличии соответствующих данных выполнять вспомогательные проверки VITRIFY и близости к экспериментальным составам.

**Научное ограничение:** прогнозы моделей не подтверждают получение стекла, его фазовое состояние или реальную пригодность. Результаты — кандидаты для экспериментальной проверки.

## Ограничения доступа и воспроизводимость

- GitHub предоставляет исходный код, но **не размещает работающий сервер** GlassDesign ML.
- Прогнозные модели `.joblib` скачиваются из Google Drive. Владельцу нужно сохранять их доступность по ссылке и достаточную квоту скачиваний.
- Временный адрес Cloudflare Tunnel меняется между запусками; доступность без VPN зависит от сети и провайдера.
- Файлы `.joblib` нужно загружать только из доверенных источников, так как их десериализация исполняет Python-код.
- Рекомендуется проводить испытания на новой среде Colab, с задачами, где подходящие составы найдены, и задачами, где подходящих составов нет.
- Для постоянного URL без зависимости от Colab и временного туннеля потребуется отдельное развёртывание на сервере с достаточной оперативной памятью.

## Исходный код

Основные компоненты: `streamlit_app.py` (веб-интерфейс), `glass380_engine.py` (подбор составов), `glass380_science.py` (дополнительная диагностика), `runtime/GlassDesignML/` (конфигурация).

Не публикуйте в репозитории токены, пароли, личные данные и необработанные исследовательские базы.
