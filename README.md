# GlassDesign ML 1.0

**Исследовательский генератор составов оксидных стёкол по заданным свойствам** — публичная демонстрация на базе расчётного ядра 391 и веб-интерфейса 409.

> **Самостоятельный запуск:** [открыть GlassDesign ML в Google Colab](https://colab.research.google.com/github/polinashidlovskaya/glassdesign-ml/blob/main/GlassDesignML_Independent_Demo.ipynb).
> Ссылка на этот блокнот остаётся постоянной. Веб-адрес `trycloudflare.com` временный и создаётся заново при каждом запуске.

## Инструкция для пользователя

1. Откройте ссылку на Google Colab выше и при необходимости войдите в учётную запись Google.
2. Выберите **«Среда выполнения» → «Выполнить все»**. Подтвердите запуск кода доверенного репозитория.
3. Colab установит программные зависимости и скачает **четыре предварительно обученные модели** из файлов автора, опубликованных для доступа по ссылке. Устанавливать Python на свой компьютер не требуется.
4. По возможности программа создаст справочный индекс экспериментальных данных **SciGlass** из открытой базы GlassPy. При проблемах с загрузкой SciGlass расчётный генератор остаётся доступен, но литературный поиск может быть ограничен.
5. В последней ячейке появится **«GLASSDESIGN ML ОТКРЫТ»** и ссылка с доменом `trycloudflare.com`. Откройте её в новой вкладке.
6. Задайте химическую систему (автоматический выбор, готовые семейства или собственный набор оксидов), концентрации и требуемые свойства; выполните подбор, изучите результаты и сохраните CSV или ZIP.

Сеанс Colab должен оставаться подключённым на протяжении работы с веб-приложением. Временный адрес меняется при каждом новом запуске. Постоянный хостинг не предоставляется. Доступность моделей зависит от открытых файлов Google Drive автора и их лимитов.

## Возможности

- Обратный подбор составов методом адаптивного генетического поиска по ограничениям **ρ**, **n**, **Tg** и **Td**.
- Прогнозирование четырьмя фиксированными моделями GlassDesign ML и дополнительная проверка GlassNet.
- Сопоставление одного и того же свойства температуры: **Td — дилатометрическое размягчение** (историческая внутренняя колонка `Tsoft_C`). Температура Littleton Tsoft сохраняется для диагностики отдельно.
- Проверка допустимых диапазонов, состава 100 мол.% и порядка температур `Td ≥ Tg` по обеим моделям; неудовлетворяющие условиям составы не выдаются как рекомендации.
- ТОП-15 разнообразных предложенных составов, подробные таблицы и экспорт CSV/ZIP.
- При доступности открытой базы SciGlass — поиск экспериментально измеренных составов и библиографии; химическое расстояние показано явно. При наличии проверенного DOI открывается страница публикации; отсутствие DOI не означает отсутствия самой статьи.
- Автоматический поиск библиографических DOI через Crossref, при доступности API — через OpenAlex. Неоднозначным публикациям DOI не присваивается.

### Важное различие между публичной и исследовательской версиями

Полная исследовательская версия 409 использует дополнительные обучающие/справочные таблицы для **эвристической оценки A/B/C/D**. Эти отдельные таблицы **не включены в общедоступный репозиторий**, поэтому рейтинг A/B/C/D **не рассчитывается в самостоятельной публичной демонстрации**. Отсутствие оценки не является плохим прогнозом.

Поиск литературы выполняется по источникам SciGlass и может быть ограничен доступностью источников, интернет-соединения и внешних сервисов. Для любой найденной статьи следует самостоятельно проверять первоисточник.

## Научные ограничения

Прогнозы двух моделей не являются независимым экспериментальным подтверждением, а их согласование не гарантирует стеклообразование, химическую устойчивость, фазовую чистоту, прозрачность или соответствие реальных свойств расчёту. Все предложенные составы предназначены для дальнейших лабораторных исследований.

## Структура программы

- `app_glassdesign_409.py` — актуальный интерфейс версии 409.
- `glass391_engine.py`, `glass390_glassnet.py`, `glass391_glassnet.py`, `glass391_recommendations.py` — расчёт и согласование прогнозов.
- `glass403_ranking.py` — ТОП-15 составов.
- `glass398_universal_literature.py`, `glass403_literature.py`, `glass405_published_table.py` — научные аналоги и библиография.
- `glass408_source_access.py`, `glass409_doi_enrichment.py` — открытие и проверка литературных ссылок.
- `runtime/GlassDesignML` — конфигурация моделей и поддерживаемых химических семейств; оригинальные модели `.joblib` скачиваются при запуске.

**Источник справочных стекольных данных:** [SciGlass (репозиторий drcassar/SciGlass)](https://github.com/drcassar/SciGlass), условия использования данных указаны в лицензии первоисточника (ODbL). [GlassPy](https://github.com/drcassar/glasspy) используется для работы с моделями GlassNet и SciGlass.

Нельзя публиковать токены, личные файлы Google Drive, закрытые обучающие таблицы или исследовательские данные без отдельной проверки прав на распространение.
