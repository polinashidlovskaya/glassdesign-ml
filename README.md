# GlassDesign ML — публичный демонстрационный запуск (шаг 409)

Обратное проектирование составов оксидных стёкол по заданным диапазонам плотности, показателя преломления, Tg и дилатометрической температуры размягчения (Td). Используются замороженные модели GlassDesign ML и независимые предсказания GlassNet. Дополнительно доступны научная диагностика, поиск экспериментальных аналогов в SciGlass и ссылки на проверенные первоисточники.

## Запуск для всех пользователей

[Открыть Google Colab](https://colab.research.google.com/github/polinashidlovskaya/glassdesign-ml/blob/main/GlassDesignML_Independent_Demo.ipynb) → **Среда выполнения → Выполнить все** → открыть полученный в последней ячейке временный адрес `trycloudflare.com`.

Нужны только браузер, Интернет и учётная запись Google. Установка Python на личный компьютер не требуется. Первый запуск загружает несколько крупных обученных моделей из Google Drive и общедоступные справочные данные из GitHub. Colab должен оставаться запущенным; адрес приложения меняется при каждом старте.

## Состав публичного релиза

- `streamlit_app.py` — интерфейс шага 409 (содержит группировку измеренных составов, DOI и экспорт результатов).
- `glass391_engine.py`, `glass390_glassnet.py`, `glass399_integrated.py` и остальные `glass*.py` — проверенные по синтаксису модули научного расчёта, диагностики и библиографии.
- `runtime/GlassDesignML` — конфигурация моделей и семейств.
- `public_data/*.csv.gz` — четыре справочные таблицы, без потерь сжатые gzip (контрольные суммы проверяются перед распаковкой).
- `public_data/index/*.part*` — три части индекса SciGlass 398, при запуске склеиваются и проверяются SHA-256.
- `public_data/source_catalog_step397.csv`, `public_data/source_doi_cache_409.json` — проверенный каталог литературы и кэш DOI.
- Архивы `ARHIV.csv.zip`, `Kod2Ref.csv.zip`, `Reference.csv.zip` при необходимости скачиваются программой из открытого репозитория источника SciGlass `drcassar/SciGlass`.
- Четыре модели `.joblib` загружаются из публично доступных файлов Google Drive автора и не входят в GitHub из-за размера.

## Важные ограничения

Программа ищет **расчётные** составы для дальнейшей экспериментальной проверки. Совпадение с данными SciGlass не заменяет измерения характеристик полученного образца; классы научной диагностики не являются вероятностью стеклообразования. Убедитесь, что сторонний файл `.joblib` получен из доверенного источника. Временная ссылка Cloudflare не является постоянно работающим сайтом.

## Воспроизводимость

Таблицы и индекс защищены контрольными суммами SHA-256. Блокнот не монтирует приватный Google Drive пользователя. При повторном запуске в Colab обновляет код ветки `main` и сохраняет уже загруженные крупные модели. Доступность запуска зависит от сервисов Google Colab, Google Drive, GitHub, PyPI и Cloudflare.
